# Agent Positioning Content Framework

目标定位：企业级 Agent 平台架构专家 / AI FDE 技术负责人 / 大模型应用架构负责人。

## 内容原则

- 不把自己包装成普通 Agent 全栈开发，而是强调平台化、企业集成、评测闭环和业务结果。
- 不伪造项目指标。没有真实数据时只保留框架，等项目实践补齐后替换。
- 每个案例都要回答：业务流程是什么、系统边界是什么、你负责什么、指标改善是什么、失败和复盘是什么。

## 后续项目实践补充字段

每个项目建议按以下结构给：

1. 项目背景：行业、业务流程、原痛点、用户/团队规模。
2. 你的角色：架构负责人、核心模块 owner、团队负责人、跨团队推进人。
3. 技术架构：Agent Runtime、工具体系、MCP/插件、RAG/Memory、权限审计、评测、可观测、模型路由、成本延迟。
4. 业务指标：流程耗时、人效提升、任务成功率、人工接管率、误调用率、token 成本、延迟、稳定性。
5. 交付过程：从 POC 到生产、灰度发布、上线门槛、事故复盘、跨团队协同。
6. 复用价值：平台能力是否被多个流程/团队复用，如何降低后续接入成本。

## 推荐优先补的三类证据

- 平台级作品：Agent Runtime、Tool-use、MCP/Skills、权限审计、Evaluation Harness、Observability。
- 业务 ROI：效率、成本、质量、稳定性、客户/业务满意度。
- 模型侧理解：模型选型、RAG/GraphRAG、function calling、长上下文、评测集、模型路由、缓存、幻觉治理。
