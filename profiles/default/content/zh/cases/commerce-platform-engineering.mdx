## 定位

这段经历不是当前简历的主攻方向，但很有加分价值：它证明我在进入 AI 平台前，已经做过大厂高流量、跨团队、多技术栈并存的复杂工程。

对高阶 Agent 平台岗位来说，这类背景能支撑稳定性、可观测、跨团队协作、平台抽象和性能治理能力。

## 淘宝直播

在淘宝直播场景中，主要负责直播间 Web 互动层微前端实施：

1. 从 Weex 单组件模式演进到 H5 微前端编排，统一布局、路由、事件总线和通信规范。
2. 支持 Weex、H5 和不同 Web 技术栈组件并存，降低新老架构过渡成本。
3. 通过 SSR 同构渲染、HTTP2/HTTP1 资源策略和渲染优化，在复杂业务与弱网环境下保障首屏体验。
4. 相关性能目标包括 FCP < 1.5s 级别体验，接近原 Weex 方案。

## 本地生活商业化

在阿里本地生活商业推广业务中，主要围绕广告投放、订单归因和商家经营数据展开：

1. 设计 shell / iframe 微前端架构，统一子应用通信、路由定义、静态资源加载和部署方式。
2. 建设 Vue 与 React 技术栈脚手架、跨平台 JsBridge、广告日志上报 SDK 和通用组件库。
3. 支持饿了么、手淘、支付宝、微信等平台的 H5 投放和小程序开发。
4. 参与从用户下单、广告计费、订单归因到商家经营分析的商业化闭环。
5. 在营销搭建与页面性能方向沉淀 SSR 方案，相关场景 FCP 提升约 40%，FCP < 1.8s。

## 高阶价值

这段经历适合压缩表达，但不能完全省略。它提供了三个关键底座：

- 高流量业务下的工程稳定性和性能意识。
- 跨团队、多技术栈、多端容器环境下的平台抽象能力。
- 日志、归因、SDK 和商业闭环意识，这些能力能迁移到 Agent 平台的 trace、tool audit 和 usage/cost 治理。
