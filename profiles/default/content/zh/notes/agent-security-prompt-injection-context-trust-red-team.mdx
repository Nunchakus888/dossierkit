## 核心判断
Prompt Injection 在 Agent 时代不再只是影响模型输出，而是试图改变 Agent 的决策链和执行行为。

## 背景
传统 LLM 只有输入和输出，而 Agent 会读取文档、调用工具、修改系统，因此恶意内容可以通过 Context 影响真实动作。

## 核心思想
PIMiner 将攻击过程 Agent 化：攻击 Agent 自动生成策略、观察目标行为、积累有效攻击模式。

## 工程抽象
安全边界需要从 Prompt Filter 升级为：
- Context Trust
- Action Governance
- Execution Isolation

所有输入都应该标记来源和可信等级。内容可以提供信息，但不能自动获得控制权限。

## 实践方案
建立 Context Firewall：
外部内容 → 来源识别 → 信任分类 → Policy 判断 → Agent Context。

Tool Output、Repository 内容、Memory 写入都需要经过同样治理。

## 关键认知
Agent Security 的核心不是让模型更听话，而是限制不可信信息影响高风险动作。
