将 ChatGPT 中已经整理完成的研究内容直接写入权威知识库，并自动发布为可分享网页。核心目标是缩短链路、减少人工下载与重复备份，同时让后续批量维护具备稳定边界。

## 核心链路

ChatGPT 负责交互式研究与内容整理；DossierKit Notes MCP 负责接收完成稿、校验结构并生成自然连贯的标题元数据与 slug；GitHub main 分支保存唯一权威 Markdown；持续集成负责校验、构建并发布到 Cloudflare Pages。

整条链路保持为：ChatGPT → MCP → GitHub → 网站。中间不保留第二份可编辑副本，也不兼容旧的手动下载流程。

## 写入原则

- 每篇笔记只包含一个一级标题，正文使用完整 Markdown。
- 调用方不传 slug 或目标路径，服务端根据标题和主题稳定生成可读地址。
- 同一标题重复保存时更新同一篇权威笔记；内容未变化时不产生无效提交。
- 所有写入都经过身份验证、结构校验与 Git 历史记录，网页只消费 GitHub 中的事实。

## 批量维护

定期研究沿用相同入口。分类、语言、摘要、内容哈希与文件位置由服务端统一生成；站点构建集中完成索引、搜索和链接发布。批量改名、迁移与质量检查通过仓库脚本执行，避免在 ChatGPT、浏览器和本地目录分别维护规则。

## 安全与运维

Cloudflare Access 提供 OAuth 登录和短期访问令牌，GitHub 凭据仅存在于部署环境。自动化部署同时验证笔记 schema、MCP 工具发现、网站构建和 OAuth 配置。网络链路使用系统 TUN，保证浏览器控制与命令行请求采用一致出口。

## 使用方式

在 ChatGPT 中完成研究后，直接提出“保存为笔记并发布”。系统调用 save_note，返回公开链接和对应提交。之后所有修订继续使用相同标题保存，外部分享链接保持稳定。
