工具的选择应由系统承担，用户只需明确目标和判断结果。

这是十万大山信息服务工作室的 Cowork 产品路演，约五分钟。Cowork 面向个人、团队与已有 Agent，把模型选择、思考程度和执行方法交给系统，让用户围绕任务目标与可用成果交流。

## 从目标到成果

路演通过供应商比较展示任务交付：用户提供候选名单、预算和模板，Cowork 组织资料核对、数据处理与文件制作，交付有出处的对比表、候选清单、询价草稿及可继续更新的工作文件。Coding 和工具调用服务于完成目标，有效方法可以整理成可复用技能。

## 三种使用方式

- 个人使用：说清目标、提供材料与偏好，按自己的方法得到成果。
- 团队协作：成员围绕共同任务共享背景，由 AI 协调不同角色推进排查、修复与验证，人负责补充事实、审阅与关键决定。
- Agent 调用：保留客户已有的模型和业务逻辑，通过任务服务补充网页操作、文件处理与执行能力。

电脑、平台和个人使用模式不应成为工作边界。产品与商业设计围绕个人订阅、团队服务及 Agent 按量调用展开。

## 演讲范围

本演讲介绍产品方向与目标体验。多人协作、跨入口连续工作与对外 MCP 服务属于产品演进设计；报价比较与故障处理用于说明使用场景。涉及发送、提交、修复或发布的操作，需要有效授权和相应责任人的确认。
