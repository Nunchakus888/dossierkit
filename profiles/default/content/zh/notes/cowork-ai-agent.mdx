工具应承担配置与协调的复杂性，让人把时间用在目标、判断和结果上。

十万大山信息服务工作室的 Cowork 产品分享，围绕数字分身、对话式自配置和连续工作展开。落地路线从本人和身边用户的个人任务开始，再聚焦中小团队运营的售后异常排查：先用范围明确的真实任务验证交付质量、人工耗时与持续使用意愿，再形成月度服务，随实际需求扩展更多平台与多人协作。

## 一句话配置自己的工作伙伴

“做支付业务的数字分身，先核对回调和近期变更。用这份业务说明，日常排查静默处理，修复由负责人确认。”

Cowork 的自配置设计把这段要求整理成角色、知识来源、工作规则、可静默推进的任务范围与负责人确认项，展示具体变更后使用。用户无需先选择模型、思考程度或场景模式。执行中按需编写代码，把验证有效的步骤沉淀为可复用 Skill，继续通过对话调整方法。角色与工具可以配置，权限由有相应职权的人授予。

## 产品场景：各角色的数字分身，带着上下文工作

数字分身了解所负责的业务，带着角色背景、知识、历史方法与明确授权处理日常任务。群里贴出一笔已支付、页面仍显示待付款的订单，直接 @Cowork，就能关联订单、支付状态、日志与近期变更，开始排查。

运营数字分身整理反馈和影响，研发数字分身追踪链路并准备修复，测试数字分身复现和验证。各角色在已有授权内并行工作，Cowork 合并证据、推进任务。需要关键决定或超出授权的动作时，具体原因、影响与处理方案交给对应负责人；获准后继续执行与核对。

更多日常工作在有限授权内静默推进。打开后的工作摘要可以呈现“10 个 Case 已处理、3 个客诉已梳理、7 个 Bug 已排查”，并提供结果、证据和处理记录。这里的数字是产品场景示意，用于说明汇总体验。

人从逐项找人、催办和确认，转向打开看结果、关键时刻做决定。处理过程中积累的知识、结论与记录，也成为下一次工作的起点。

## 第一步：从自己和身边用户用起来

手机上收到一批反馈，回到电脑前又得重新找资料、重说背景，这是许多人熟悉的工作片段。Cowork 从本人和身边用户的日常任务开始：手机交代“把今天的反馈和工作记录整理成简报，列出待办”，晚上打开电脑，补充资料，接着同一份工作往下做。角色、方法和已有进度跟着人走，云端承担执行与环境准备，用户无需部署专属电脑或配置本地运行环境。

起步连接手机和电脑 Web 的工作，再按开放能力接入微信、飞书等熟悉的渠道。工作跟着人走，换个入口，接着完成。客户端访问仍需要网络；实际应用以任务记录和已接入范围为依据。

## 换平台，也带着自己的工作积累

在已接入的 Agent 平台，说一句“接着手机里那份简报做”。同一个数字分身带着角色、已授权知识、工作记忆、处理记录、结论和未完成步骤继续，保留用户原来的模型与业务流程。

Codex 和 Claude Code 都支持 MCP，为标准能力接入提供基础。[Codex 官方文档](https://developers.openai.com/codex/mcp)、[Claude Code 官方文档](https://code.claude.com/docs/en/mcp)。WorkBuddy 等平台按各自开放接口适配；身份绑定、任务关联与有效授权决定可携带的上下文。

缺少网页或文件操作能力的 Agent，可按接口调用 Cowork 的云端执行能力，随后取回证据、文件与状态，在原流程继续交付。按需 Coding，把验证有效的方法整理为 Skill。跨平台扩展随实际需求推进，接入以真实兼容验证为准。

## 从个人升维：聚焦中小团队的售后异常排查

首个业务场景面向中小团队的运营，先聚焦“已支付、订单仍显示待付款”这一类高频异常。运营提交客户反馈、订单和支付记录，Cowork 结合业务规则与已授权日志，把分散的信息整理成异常处理依据。

交付物是一份异常处理单：发生了什么、时间线与证据在哪里、影响哪些订单、原因查到哪里，以及下一步动作由谁决定。区分已证实事实和待确认项，由运营核对结论。修复和发布等动作按负责人授权推进，多人协同与自动修复作为扩展方向。

这一步聚焦可用交付，减少运营找资料、搬运信息与重复排查的人工投入。范围明确的客户验证先约定一类异常、一个负责团队、一套资料来源和交付标准，保留真实任务与结果证据。

## 把一次问题处理，做成持续的月度服务

先记录同类任务的人工处理基线，再记录 Cowork 辅助后的实际人工投入，计入资料整理、核对、修订和返工。由业务负责人确认处理依据是否可用，同时观察客户是否主动再次提交任务，以及是否愿为下一周期付费。意愿反馈、实际付费与续费分别记录。

服务价值体现在可用交付、更少的完整人工耗时，以及客户的持续使用和付费。月度服务按约定场景和处理额度收费，持续维护业务知识与排查方法，定期回看交付质量、人工耗时和续费情况。先做成一个高频问题的付费交付，再扩展更多场景、渠道与协作能力。

以上为客户验证和商业化安排，不以未经核验的节时比例、价格或收入数据支撑。

## 产品竞争力

竞争力贯穿整个任务链：配置通过对话完成，数字分身在有限授权内静默处理工作，已有平台与 Agent 继续使用，积累的上下文持续复用。个人化与持续服务参考了 [Muse 官方产品设计](https://introducing.muse.ai/)，分享重点放在 Cowork 的自配置、角色上下文、连续工作与范围明确的业务交付。

## 十万大山的愿望

George 有十年软件开发经验、大厂研发经历，专注企业 AI Agent 解决方案。“十万大山”承载着让技术越过重重使用门槛的愿望：从改善一个人的工作开始，让更多人拥有过去需要一个团队才能具备的能力，随时随地，在自己熟悉的平台继续工作。

以上产品场景与落地路线用于说明设计理念及使用方式。工作摘要数字为示意，非实测业绩。数字分身、多人角色编排、持续工作、跨入口记忆、自配置和对外服务按实际接入范围使用；静默工作保留可追踪的进度与记录，执行在有效授权与对应业务系统的权限内推进。
