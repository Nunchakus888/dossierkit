用 macOS 自带命令开启，**插电和电池供电都生效**。

## 1. 开启

打开终端，执行并输入管理员密码：

```bash
sudo pmset -a disablesleep 1
```

开启后即可合盖继续运行。

## 2. 查看状态

```bash
pmset -g
```

看 `SleepDisabled`：**1 = 已开启，0 = 已关闭**。

## 3. 恢复正常睡眠

```bash
sudo pmset -a disablesleep 0
```

**关闭终端不会自动恢复。合盖运行时保持通风，装包前恢复睡眠。**

<details>
<summary>原理与实测（按需展开）</summary>

`disablesleep` 是禁止系统睡眠的全局开关，影响插电和电池状态。不能简单改成 `-c` 来实现“仅插电生效”。依据：[Apple pmset 源码](https://github.com/apple-oss-distributions/PowerManagement/blob/main/pmset/pmset.m)。

2026-11-13，在 Apple 芯片 MacBook Pro（Mac16,1、macOS 26.2）上，电池供电合盖实测 104 秒：52 条心跳连续更新，最大间隔 3 秒，期间仍可执行新命令。恢复命令也已验证。其他机型、系统版本和长时间运行未验证。

</details>
