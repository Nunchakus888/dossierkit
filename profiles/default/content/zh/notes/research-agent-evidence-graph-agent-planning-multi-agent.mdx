## 核心问题
传统 Research Agent 通常采用：

```text
搜索 → 总结 → 输出
```

问题：

- 无法确认关键结论是否有证据
- 发现缺失信息后只能重新生成
- 搜索成本高

## 核心思想
AREX 将研究过程转变为约束驱动循环：

```text
生成候选结果
    ↓
提取约束和声明
    ↓
验证证据覆盖
    ↓
定位未满足部分
    ↓
定向搜索补充
    ↓
再次验证
```

## 关键方法

### Evidence-driven Research

维护：

- Claim
- Evidence
- Confidence
- Missing Information

避免无依据扩展。

### Incremental Improvement

不是重新生成整个答案，而是只修复不足部分。

优势：

- 降低 Token 成本
- 减少已有正确内容被破坏
- 提高长期任务稳定性

## 工程落地方案

适用于：

- 技术调研 Agent
- 市场分析 Agent
- 投研 Agent
- 企业知识 Agent

推荐架构：

```text
Planner
 ↓
Research Executor
 ↓
Evidence Graph
 ↓
Verifier
 ↓
Gap Detector
 ↓
Focused Search
```

## 对 Agent 工程师的意义

未来高阶 Research Agent 不只是连接搜索 API，而需要：

- Evidence Management
- Constraint Tracking
- Verification Loop
- Cost-aware Planning

这也是企业级 Agent 与普通 Chatbot 的核心差异。
