## Hypothesis

If tool-use failures are converted into chosen/rejected preference pairs, a small model can learn more stable tool selection behavior and reduce clearly invalid parameter generation.

## Dataset

The data came from sanitized badcases, crafted boundary examples, and a small set of synthetic preference pairs. Each example kept the task goal, available tools, business constraints, chosen behavior, and rejected behavior.

## Evaluation

The evaluation looked beyond win-rate. It also tracked tool selection accuracy, parameter validity, refusal quality, and whether human handoff was triggered.

## Result

The small-scale experiment improved tool selection stability, but gains on complex multi-step tasks were limited. Future work should separate task decomposition from tool selection.
